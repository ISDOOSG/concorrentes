# Story E1.2 — Telas de signup e login

**Status:** Draft
**Epic:** [E1 — Auth + Onboarding](../epics/E1-auth-onboarding.md)
**Created by:** @sm (River)
**Created at:** 2026-04-26
**Depende de:** E1.1

## User Story

**Como** novo usuário do produto
**Quero** poder me cadastrar com e-mail e senha e entrar na minha conta
**Para** começar a usar a plataforma de análise de concorrentes.

## Acceptance Criteria

- [ ] Rota `/signup` com form: full_name (opcional), e-mail, senha, confirmação de senha
- [ ] Rota `/login` com form: e-mail, senha + link "Esqueceu a senha?" (placeholder, não funcional em E1)
- [ ] Validação Zod: e-mail formato válido, senha mínimo 8 chars, confirmação igual à senha
- [ ] Mensagens de erro inline (campo a campo) e toast em erros de auth do Supabase
- [ ] Após signup bem-sucedido → redirect para `/dashboard`
- [ ] Após login bem-sucedido → redirect para `/dashboard`
- [ ] Links recíprocos: signup tem "Já tem conta? Entrar" / login tem "Sem conta? Cadastrar"
- [ ] Forms acessíveis (labels, ARIA, focus management)
- [ ] Submit duplo bloqueado com `isSubmitting` (botão disabled + spinner)

## Tasks / Subtasks

- [ ] **T1** Criar rota `src/routes/signup.tsx`
  - [ ] T1.1 Layout simples centralizado (Card do shadcn)
  - [ ] T1.2 Form com React Hook Form + Zod schema
  - [ ] T1.3 Submit chama `supabase.auth.signUp({ email, password, options: { data: { full_name } } })`
  - [ ] T1.4 Tratar erros (e-mail já existe, senha fraca etc.) com toast (sonner)
  - [ ] T1.5 Em sucesso: `navigate({ to: '/dashboard' })`
- [ ] **T2** Criar rota `src/routes/login.tsx`
  - [ ] T2.1 Mesmo layout do signup
  - [ ] T2.2 Submit chama `supabase.auth.signInWithPassword({ email, password })`
  - [ ] T2.3 Em erro 400 → mensagem "E-mail ou senha incorretos" (não vazar qual é)
  - [ ] T2.4 Em sucesso: redirect `/dashboard`
- [ ] **T3** Criar `src/lib/auth-schema.ts` com Zod schemas reutilizáveis (`signupSchema`, `loginSchema`)
- [ ] **T4** Atualizar `src/routes/index.tsx`
  - [ ] T4.1 Se houver session → redirect `/dashboard`
  - [ ] T4.2 Senão → mostrar landing simples com CTAs "Entrar" e "Criar conta"

- [ ] **T5** Smoke test manual: signup novo → confirmar `profiles` criado → logout → login → logout

## Dev Notes

- **shadcn components a usar:** `Card`, `CardHeader`, `CardContent`, `Input`, `Button`, `Label`, `Form` (já instalados)
- **Toast:** usar `sonner` (já instalado). `import { toast } from 'sonner'` e renderizar `<Toaster />` no `__root.tsx`
- **Confirmação de e-mail desabilitada em DEV** (decisão de E1.1): após `signUp`, o usuário já está autenticado imediatamente
- **Atenção ao redirect:** `navigate` do TanStack Router não bate com `window.location.href`; usar `useNavigate` corretamente
