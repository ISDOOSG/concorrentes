# Story E1.3 — Layout protegido `_authed/` + logout

**Status:** Draft
**Epic:** [E1 — Auth + Onboarding](../epics/E1-auth-onboarding.md)
**Created by:** @sm (River)
**Created at:** 2026-04-26
**Depende de:** E1.2

## User Story

**Como** usuário autenticado
**Quero** acessar uma área protegida com layout próprio (header + main) e poder fazer logout
**Para** consumir as funcionalidades do produto sem expor rotas internas a visitantes não-logados.

## Acceptance Criteria

- [ ] Rota-pai `src/routes/_authed.tsx` (layout route do TanStack Router) valida session via `beforeLoad`
- [ ] Se não houver session → throw redirect para `/login` com `search.redirect` para retornar após auth
- [ ] Header global com: logo "Análise de Concorrentes", nav (`Dashboard`, `Competidores`, `Alertas`, `Settings`), avatar com dropdown (e-mail + botão "Sair")
- [ ] Logout limpa session no Supabase + invalida queries do TanStack Query + redirect `/login`
- [ ] Página `/dashboard` placeholder com texto "Olá, {full_name || email}" e badge "Plano: free • Quota: 0/5"
- [ ] Login bem-sucedido respeita `search.redirect` se presente, senão vai para `/dashboard`

## Tasks / Subtasks

- [ ] **T1** Criar layout route `src/routes/_authed.tsx`
  - [ ] T1.1 `beforeLoad` chama `supabase.auth.getSession()` server-side
  - [ ] T1.2 Se ausente → `throw redirect({ to: '/login', search: { redirect: location.href } })`
  - [ ] T1.3 Carrega `profiles` row do user (TanStack Query) e expõe via context
- [ ] **T2** Criar `src/components/app-header.tsx`
  - [ ] T2.1 Logo (texto simples por enquanto)
  - [ ] T2.2 Nav links com `<Link from="/_authed">`
  - [ ] T2.3 DropdownMenu (shadcn) com avatar (iniciais), e-mail, "Sair"
  - [ ] T2.4 Botão "Sair" chama `supabase.auth.signOut()` + `queryClient.clear()` + navigate `/login`
- [ ] **T3** Criar rota `src/routes/_authed/dashboard.tsx`
  - [ ] T3.1 Placeholder com saudação e badge de plano
  - [ ] T3.2 CTA "Adicionar primeiro competidor" disabled (E2 implementa)
- [ ] **T4** Atualizar `src/routes/login.tsx` para honrar `search.redirect`
  - [ ] T4.1 Schema do search: `z.object({ redirect: z.string().optional() })`
  - [ ] T4.2 Após login → `navigate({ to: search.redirect ?? '/dashboard' })`
- [ ] **T5** Smoke: tentar acessar `/dashboard` deslogado → vai para login → loga → volta para `/dashboard`

## Dev Notes

- **Layout routes do TanStack Router:** prefixo `_` cria layout sem segmento de URL. `_authed.tsx` envolve `_authed/*.tsx` filhos
- **`beforeLoad`:** rodar SSR-safe. Em Cloudflare Workers, `supabase.auth.getSession()` precisa de server client com cookies. Verificar se `src/integrations/supabase/client.ts` tem variante server
- **`queryClient.clear()` no logout:** evita que queries cacheadas vazem dados de outro usuário se ele logar em sequência
- **shadcn:** `DropdownMenu`, `Avatar`, `Badge` (todos já instalados)
